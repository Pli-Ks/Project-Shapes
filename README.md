\# Project Shapes



A 2D action game prototype developed with Godot Engine.



\## About the Project



Project Shapes is an experimental action game focused on movement, combat, and the interaction between different geometric forms.



The project is being developed as a learning project, with an emphasis on gameplay programming, game design, and iterative development.



\## Development Status



\*\*Current stage:\*\* Project setup.



Planned initial features:

\- Player movement and jumping

\- Distinct geometric forms

\- Form switching

\- Combat mechanics

\- Basic enemies and arenas



These features are planned and may change during development.



\## Built With



\- Godot Engine

\- GDScript

\- Git and GitHub



\## Running the Project



1\. Clone or download this repository.

2\. Open `project.godot` using Godot Engine.

3\. Run the project from the editor once a main scene has been created.



\## Project Goals



\- Learn and practice game development.

\- Build a playable prototype incrementally.

\- Document development progress.

\- Maintain a public portfolio project.
